📄 Reports Center - Full Match Analysis

How to use: 1. Play match 2. Go to Reports 3. View On Screen 4. Print / PDF / TXT

Includes: Match-wise, Player-wise, Graphs, AI Summary, Cap/Crown, Entry Rank

📖 How to Use Reports - Guidance

1. Match-wise: Shows current score, target, innings, CRR/RRR, runs per over chart

2. Playerwise: All players with 🧢50 / 👑100 badges, entry rank # and team score when came, batting/bowling stats

3. Graphs: Visual bar charts for Top 8 batters (runs) and bowlers (wickets), runs per over

4. AI Summary: Performance analysis - century, fifty, economical, expensive, match summary

5. Actions: View On Screen = show full text, Print = print page, PDF = download HTML, TXT = download text
